# task-java-enums-dates-records

**Descripció**:
- Aquesta tasca recull tres temes fonamentals de Java que t’ajudaran a escriure codi més clar, segur i modern: 
- Els enums per representar valors finits i controlats,
- Les dates i hores amb l’API de Java Time per treballar amb el temps de forma robusta,
- Els records, una novetat de Java per declarar classes de dades immutables amb menys codi.
