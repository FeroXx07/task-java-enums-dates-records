# Level 2 – Dates i hores

##  Enunciat de l'exercici
Treballar amb dates i hores és fonamental en molts projectes. Java ofereix l’API java.time des de la versió 8 per fer-ho de forma robusta i clara, evitant els problemes del vell Date.

Aprendràs a representar el temps amb precisió (LocalDate, LocalTime, LocalDateTime), fer càlculs temporals, comparar dates, formatar-les i treballar amb agendas o planificacions. És una eina clau per desenvolupar aplicacions que depenen del calendari.
Exercicis:

    Mostra la data i hora actual amb LocalDate, LocalTime i LocalDateTime.
    Calcula la diferència entre dues dates (amb Period o Duration).
    Afegeix o resta dies, mesos o hores a una data.
    Formata una data amb DateTimeFormatter (en diversos formats).
    Crea una funció que digui si una data passada com a paràmetre és anterior a avui.
    Crea una agenda amb cites guardades com a LocalDateTime i mostra les pròximes.
